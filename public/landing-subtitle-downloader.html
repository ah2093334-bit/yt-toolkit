    Frequently Asked Questions

    What's the difference between subtitles and captions here?

    On YouTube, both terms usually refer to the same underlying text track. This tool pulls whichever caption track YouTube has available for the video.

    Can I get subtitles in a different language?

    This tool pulls the default caption track YouTube provides for the video. Availability of additional language tracks depends entirely on what the uploader or YouTube's auto-captioning has generated.

    Is there a limit on how many videos I can check?

    The free tool allows 5 extractions per day per visitor.

    Does this download an .srt file?

    Currently the tool returns clean, copyable plain text rather than a formatted .srt/.vtt file — ideal for repurposing into blog posts, translations, or notes.
